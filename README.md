# 合同盖章工具（contract-sealer）

给扫描版合同（PDF / 图片）盖章的本地桌面工具：物理尺寸 1:1、骑缝章（M2）、手写签名、随机真实感效果。全程离线，不修改原始文件。

> 设计文档见《项目方案.md》（v1.3）。本工具仅限本单位已授权印章的内部流程使用，不得用于伪造印章/签名；打包产物不得对外分发（PyMuPDF 为 AGPL）。

## 运行

**方式一（免安装）**：双击 `合同盖章工具.exe`（PyInstaller 单文件，120MB）。

**方式二（源码）**：

```bat
:: 双击 启动.bat，或：
.venv\Scripts\python.exe -m app.main
```

首次使用：打开合同 → 右侧"导入图片…"导入印章/签名照片（自动抠图，录入真实尺寸：公章量直径，签名量宽度）→ 选中后"盖到当前页" → 拖拽/微调 → 导出。

## 功能

**M1 基础**：PDF / JPG / PNG / BMP / TIFF 导入，多图合成文档；逐页预览、滚轮缩放；墨迹自动抠图（红章 + 蓝黑签名）；盖章按真实物理尺寸 1:1，缩放/旋转/不透明度，方向键 0.1mm 微调，实时毫米显示；随机效果（角度/色度/蒙尘，种子化可复现）；纸边校准（比例自动检测 + 手动输入）；压平导出 PDF、原子写、文件名防覆盖、`.sealog` 种子落盘。

**M2 骑缝章**：随机宽度切片平铺（宽度之和恒等，拼合数学必然还原）；逐页微抖动（硬上限内）；左/右侧边、页范围、内缩、垂直位置可调；**拼合预览**按真实导出结果渲染，确认后才应用；最小切片宽度 1.5mm 约束（页数过多时明确拒绝）；切片为锁定记录，导出时不重采样（所见即所得）。

**M3 打磨**：页面旋转（90°/180°，印章坐标联动）；自动纸边检测（OpenCV 透视校正 + A4 校准）；落款模板（保存/套用，存 %APPDATA%）；批量导出（多文件套用同一模板到首/末页）；PyInstaller 打包单文件 exe。

## 印章库

存放在本机 `%APPDATA%\contract-sealer\seals\`（PNG + JSON 元数据）。**印章是敏感资产，请妥善保管该目录。**

## 开发

```bat
.venv\Scripts\python.exe -m pytest tests -q
```

架构：UI 层（app/）只操作物理 mm，core 层（core/）负责全部像素换算与算法，可脱离 GUI 测试。

## 已知限制 / 后续方向

- 双骑缝（左右两侧各一枚）、程序生成印章：方案中列为 P2/P3，未实现
- 自动纸边检测依赖纸/背景亮度差，纯白无边扫描件会检测失败（回退手动校准，不静默假定）
- 蒙尘噪声观感、抠图对复杂照片的鲁棒性，需在实际使用中收集反馈迭代
