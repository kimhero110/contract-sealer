# 合同盖章工具（contract-sealer）

> 月底 30 份合同要盖章，你打开 PS，三小时后手腕抽筋、血压拉满、骑缝章还切歪了两份。
> 这个工具就是为了终结这种日子而生的。

把公章"盖"到扫描版合同（PDF / 图片）上的本地桌面小工具。**盖出来的章和真章一样大**（物理尺寸 1:1，打印出来拿尺子量，误差不超过 1mm——比你自己盖得还准），还能一键盖骑缝章、附上手写签名、补一个落款日期，每次的章迹都带一点随机手感，不会假得像复制粘贴。

全程离线运行，不联网、不上传、不偷看你的合同——它连网卡都懒得理。

## 三大绝活

### 1. 物理尺寸 1:1 📏

导入印章时录入真实直径（公章一般 40/42mm，拿尺子量一下你的章），之后盖出来的每一个章打印出来都和真章分毫不差。扫描件歪歪扭扭、手机拍照带黑边？没关系，纸边校准伺候（手动量一下，或者让 OpenCV 自动找纸边）。

### 2. 骑缝章，一键的那种 ✂️

盖章界的期末考试。工具会把印章按页数切成竖条（宽度随机，更像真的），每页贴一条在纸边上，拼回去又是一枚完整的章——**数学保证能拼回去**，不是玄学。盖之前还有"拼合预览"让你先睹为快。页数太多切得太细？它会直接拒绝你，而不是让你拿着 0.4mm 的红线去丢人。

左侧开口也支持，而且页序会自动镜像：验章时往左扇开，从左到右看到的是最后一页到第一页，切片必须反着发才拼得回去。拼合预览会告诉你该往哪边扇。

### 3. 随机手感 🎲

真章每次盖出来都不一样：角度歪一点、印泥浓一点淡一点、偶尔缺个油。这个工具全给你安排上了——角度、色度、蒙尘、切片宽度全都带小幅度随机，由随机种子驱动，**每次导出的章迹都是绝版**。种子会记进 `.sealog` 小本本，想复现随时能复现。

### 4. 落款日期 📅

盖完章还得填日期？菜单「插入 → 加盖日期」（Ctrl+D），默认就是系统当天，想改日期、改格式（`2026年09月11日` / `2026-09-11` / `2026/09/11` / `2026.09.11`）、改字高都随你。字高填 4.5mm，打印出来量到的就是 4.5mm——和印章走的是同一套物理尺寸管线。日期不加随机手感：打印/书写的日期本来就没有印泥深浅，加了反而假。

### 彩蛋：手写签名 ✍️

白纸上签个名，拍个照丢进来，自动抠图入库。落款处"公章+法人章+签名"全家桶，一键摆好。签名还能保存成模板，下次直接"末页落款套餐，谢谢"。

## 快速上手

**下载即用（推荐）**：

| 平台 | 下载 | 说明 |
|---|---|---|
| GitHub | [Releases](https://github.com/kimhero110/contract-sealer/releases) | `contract-sealer-vX.Y.Z.exe` 单文件，双击即用 |
| Gitee（国内更快） | [发行版](https://gitee.com/xu512/contract-sealer/releases) | `contract-sealer-win-vX.Y.Z.7z`，用 7-Zip 解压后运行（Gitee 附件限 100MB，所以压缩了一下） |

都是 Windows 版，不需要装 Python。

**源码运行**：

```bat
python -m venv .venv
.venv\Scripts\pip install PyMuPDF opencv-python-headless Pillow numpy PySide6
.venv\Scripts\python.exe -m app.main
```

上手流程：打开合同 → 右侧"导入图片…"喂一张印章照片（自动抠图）→ 填真实尺寸 → "盖到当前页" → 拖到落款处 → Ctrl+E 导出。原件？一根汗毛都不会动，导出的永远是新文件。

导出时会弹另存为，**输出目录随你挑**；挑过一次就记住了，下次默认还去那儿。想改回"跟源文件放一块"，菜单「文件 → 输出目录」点一下就恢复。

## 功能一览

- **盖章核心**：PDF/图片导入；墨迹自动抠图（红章+蓝黑签名）；物理尺寸 1:1；随机真实感（角度/色度/蒙尘，可复现）
- **日期戳**：默认系统当天，可自定义日期/格式/字高，同样按物理尺寸落章
- **交互**：鼠标点哪盖哪、单击移位、方向键 0.1mm 微调、画布所见即导出（正片叠底实时渲染）
- **撤销/重做**：Ctrl+Z 撤销、Ctrl+Y 重做，盖歪了还能 Ctrl+R「重盖」——撤掉重新点位置，换一次手感
- **文档管理**：追加导入更多文件、页列表多选删页（可撤销）、一键关闭当前文档
- **骑缝章**：随机宽度切片、自动贴合真实纸边、拼合/页面双预览、整组微调与删除
- **校准**：四点点选→透视拉正为 A4、自动纸边检测、非 A 系纸提醒
- **批量**：落款模板 + 骑缝章批量导出，带进度条，输出目录可指定
- **安全与性能**：压平导出、原子写、绝不覆盖已有文件、全程离线、页面懒加载（大文档不吃内存）

## 开发

```bat
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m pytest tests -q   # 全绿才算完
.venv\Scripts\ruff check .                    # 同样要全绿
```

没装 PySide6 的机器（比如纯 Linux CI）上，GUI 用例会自动 skip，core 层的算法测试照跑——这是 core/app 分层的直接好处，也是 CI 里单独有一个"无 Qt"job 的原因。依赖版本锁在 `requirements.txt`，升级请改文件、跑测试、再提交。

架构一句话：UI 层（`app/`）只说"毫米"，core 层（`core/`）干所有像素换算的脏活累活，全部算法可脱离 GUI 测试。测试素材是程序生成的**合成**图片（`tests/fixtures/generate_fixtures.py`）——真章永不入库，这是底线。

设计文档在《项目方案.md》，里面记录了两轮工程评审抓出来的所有坑（包括"骑缝章两种几何模型互相矛盾"这种差点酿成大错的），欢迎围观。

## 严肃三秒钟（法律与安全）

- 本工具仅供**本单位已授权印章**的内部流程使用。拿它伪造印章或签名是**犯罪**，不要干，干了也别说认识我。
- 印章库存放在你本机的 `%APPDATA%\contract-sealer\seals\`（macOS/Linux 下分别在 `~/Library/Application Support` 和 `$XDG_CONFIG_HOME`）。那是你的公章，请像对待真章一样对待这个文件夹。
- 导出的 PDF 默认压平：印章不再是可以单独拖出来的图层对象。**这不等于"提取不了"**——任何人都能把整页图裁出印章。压平防的是顺手一拖就复用，不是防专业人士。
- 导出的 PDF 是整页位图。原件里可选中、可搜索的文字在导出件里不再是文字，需要保留文字层的场景请另想办法。
- **授权：本项目以 [GNU AGPL-3.0](LICENSE) 发布。** 依赖 PyMuPDF 同为 AGPL，触发条件是**分发**而不是卖钱：只要你把程序（含 exe）给到本组织之外，就必须一并提供对应源码并沿用 AGPL。内部自用不受影响。

## 已知限制

- 双骑缝（左右开弓）、程序生成印章：还在愿望清单上躺着
- 骑缝章要"换手感"需重新打开骑缝章对话框（切片参数不重存）；骑缝切片也不支持单片「重盖」
- 自动纸边检测靠纸/背景亮度差，纯白无边扫描件会优雅地失败并请你手动校准
- 中文日期格式需要系统装有中文字体。没有的话程序会明确报错并建议换纯数字格式，**不会**给你画一排豆腐块
- 日期戳不进落款模板（它的"印章"是临时合成的，不在库里）
- 蒙尘手感的"像真程度"取决于印泥物理学造诣，欢迎提 Issue 交流盖章心得
